# Mrudu Atelier landing page

A React + Vite + TypeScript landing page concept with a 3D floating cookie scene.

## Run locally

1. Install Node.js 20.19+ or 22.12+.
2. In this folder, run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the localhost address printed by Vite (typically http://localhost:5173).

## Stack
- React + TypeScript + Vite
- Three.js via React Three Fiber and Drei for the interactive 3D cookie
- Motion for reveal animations
- CSS for bespoke responsive styling

This is a first visual direction; replace CSS-built menu artwork with product photography and connect map/order links before launch.
